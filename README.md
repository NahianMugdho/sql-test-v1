# SQL ও Database প্রস্তুতি সাইট

তত্ত্ব, কুইজ ও MySQL ব্যবহারিক —  পরীক্ষার জন্য বাংলা-মিশ্র গাইড।

## এই সাইটে কী আছে

| অংশ | কী পাবে |
|---|---|
| **তত্ত্ব + কুইজ** | ৭টি সংক্ষিপ্ত অধ্যায় (প্রতিটির নিচে MCQ ও ফাঁকা পূরণ কুইজ, "শাফল" বাটনে নতুন প্রশ্ন) |
| **📘 বিস্তারিত তত্ত্ব** | ER, Key, Relational Algebra, SQL, JOIN, Subquery, Normalization, Transaction, Index ইত্যাদি পূর্ণাঙ্গ অধ্যায় |
| **📝 অনুশীলন প্রশ্ন** | Part A (৪০টি এক লাইনের) ও Part B (২০টি বর্ণনামূলক), প্রতিটির নিচে "উত্তর দেখো" |
| **ব্যবহারিক (MySQL)** | বাংলা-মিশ্র সূত্র, ৩টি ডেটাবেজ (Bank, ICML, Employee), মোট ৩৬টি সমস্যা |

## কীভাবে শিখবে (ধাপে ধাপে)

### ধাপ ১: তত্ত্ব পড়ো (১ম–২য় সপ্তাহ)
1. বাম পাশের মেনু থেকে **১. ডেটাবেজ পরিচিতি** দিয়ে শুরু করো এবং সংক্ষিপ্ত অধ্যায়গুলো পরপর পড়ো।
2. প্রতিটি অধ্যায় শেষে নিচের **কুইজ** দাও। ভুল হলে ঠিক উত্তর দেখে সেই অংশ আবার পড়ো।
3. **শাফল** চেপে নতুন প্রশ্ন নিয়ে অন্তত ৩ বার দাও, যতক্ষণ না ৮০%+ স্কোর আসে।
4. এরপর **📘 বিস্তারিত অধ্যায়গুলো** পড়ো, বিশেষ করে ৫–৯ (SQL, Aggregate, JOIN, Subquery, Normalization)। এগুলো পরীক্ষায় সবচেয়ে বেশি আসে।

### ধাপ ২: নিজের কম্পিউটারে MySQL চালু করো
ব্রাউজারের চেকার সুবিধাজনক, কিন্তু আসল অভ্যাস হয় আসল MySQL-এ।
1. **XAMPP** ইনস্টল করো, Control Panel থেকে **Apache** ও **MySQL** Start করো।
2. ব্রাউজারে `http://localhost/phpmyadmin` খোলো, উপরের **SQL** ট্যাবে কুয়েরি চালাও।
3. (বিকল্প) MySQL Workbench বা অনলাইনে DB Fiddle ব্যবহার করতে পারো।

### ধাপ ৩: ব্যবহারিক করো (৩য় সপ্তাহ থেকে — সবচেয়ে গুরুত্বপূর্ণ)
1. উপরের **ব্যবহারিক (MySQL)** ট্যাব খোলো, **পরিচিতি, সূত্র ও সেটআপ** পাতায় যাও।
2. **সূত্র** টেবিলটা মুখস্থ করার চেষ্টা কোরো না, ২–৩ বার দেখো। বাংলা-মিশ্র সূত্র (যেমন `UPDATE টেবিল SET কলাম = নতুনমান WHERE শর্ত;`) বুঝে নিলে আসল SQL লেখা সহজ হয়।
3. সেখানকার **CREATE + INSERT কোড** কপি করে phpMyAdmin-এর SQL ট্যাবে চালাও, তাহলে টেবিল ও ডেটা তৈরি হবে।
4. এরপর **সমস্যা ১** থেকে ধরে ধরে এগোও:
   - আগে প্রশ্ন পড়ে **নিজে লেখো**, সূত্র দেখে নিতে পারো।
   - **উত্তর মেলাও** চাপো। সাইট তোমার কুয়েরি আসল ডেটায় চালিয়ে ফলাফল মিলিয়ে দেখে, তাই যেকোনো সঠিক ভঙ্গিতে লিখলেই "ঠিক" দেখাবে (alias, বড়-ছোট হাতের অক্ষর, JOIN-এর ভিন্ন ধরন)।
   - ভুল হলে **তোমার আউটপুট** টেবিল ও এরর বার্তা দেখো।
   - আটকে গেলে **সম্পূর্ণ কোড ও আউটপুট দেখো**, তারপর কোডটা **না দেখে আবার লেখো**।
5. **ফাঁকা পূরণ** সমস্যায় শুধু ফাংশন বা keyword বসাতে হয় (যেমন `____(Balance)`-এ `AVG`)।
6. একই সমস্যা পরদিন আবার সমাধান করো। পরীক্ষার জন্য এটাই সবচেয়ে কার্যকর।

| সেট | সমস্যা | কী শেখায় |
|---|---|---|
| Bank DB | ১–৯ | GROUP BY, HAVING, JOIN, UPDATE |
| ICML | ১০–২৪ | CASE, subquery, LEFT JOIN, duplicate, nth highest |
| Employee | ২৫–৩৬ | self join, EXISTS, ROW_NUMBER, top-N |

### ধাপ ৪: পরীক্ষার প্রস্তুতি (শেষ সপ্তাহ)
1. **📝 অনুশীলন প্রশ্ন** সময় ধরে নিজে লেখো, তারপর **উত্তর দেখো** দিয়ে মেলাও।
2. যেসব কুইজ প্রশ্নে ভুল হয়েছে, সেই অধ্যায় আবার পড়ো।
3. **৩৬টি সমস্যা** না দেখে শুরু থেকে শেষ পর্যন্ত আবার সমাধান করো।
4. শেষ দিন **📘 ১২. Last-minute Cheat Sheet** একবার পড়ো।

## এই মনে রাখলে ভুল কম হবে
- **WHERE vs HAVING:** WHERE group-এর আগে row ছাঁকে, HAVING group-এর পরে।
- **NULL:** তুলনায় `= NULL` নয়, `IS NULL`। `NOT IN`-এর তালিকায় NULL থাকলে ফল খালি আসে।
- **UPDATE/DELETE:** আগে একই WHERE দিয়ে SELECT চালিয়ে দেখো।
- **COUNT(\*) vs COUNT(কলাম):** প্রথমটি NULL-সহ গোনে, দ্বিতীয়টি NULL বাদ দেয়।
- **ক্রম মনে রাখো:** FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT।



## নতুন প্রশ্ন বা সমস্যা যোগ করা
সব প্রশ্ন-উত্তর **`data.js`**-এ। ফাইলের শুরুতে কোথায় কী আছে লেখা আছে। যেখানে যোগ করবে সেখানে `// ➕` কমেন্ট আছে:
- **কুইজ:** প্রতি অধ্যায়ের `quiz` অ্যারের শেষে। MCQ: `{t:'mcq',q:'প্রশ্ন',o:['ক','খ','গ','ঘ'],a:0}` (a = সঠিক অপশনের নম্বর, ০ থেকে শুরু); ফাঁকা পূরণ: `{t:'fill',q:'বাক্য ____ ফাঁকা',a:['উত্তর']}`।
- **Bank সমস্যা:** `P` অ্যারের শেষে।
- **ICML সমস্যা:** `P.push(...)`-এর শেষে।
- **Employee সমস্যা:** শেষের `P.push(...)`-এ।
- **অনুশীলন প্রশ্নের উত্তর:** `ANS` অ্যারেতে।

## জানা সীমাবদ্ধতা
- **ইন্টারনেট লাগে:** উত্তর মেলানোর SQL ইঞ্জিন (sql.js) cdnjs থেকে লোড হয়। ইন্টারনেট না থাকলে শুধু লেখা মেলানো হয়।
- **ব্রাউজারে চলে SQLite, MySQL নয়:** সাধারণ SELECT, JOIN, GROUP BY, UPDATE একই চলে। তবে MySQL-এর নিজস্ব ফাংশন (যেমন `CURDATE()`, `YEAR()`) সাইটের চেকারে এরর দেখাবে। সেগুলো নিজের MySQL-এ চালিয়ে দেখো।
- **কুইজ:** সব অধ্যায়ে এখনো ২০টি প্রশ্ন নেই। প্রশ্ন বাড়ালে শাফল আরও ভালো কাজ করবে।
- **PL/SQL:** Oracle-এর Function, Procedure, Trigger সাইটে চালানো যায় না। এগুলো তত্ত্বে দেখো।
